## Описание процесса P1

### Участники
- **Пациент** — инициирует регистрацию
- **Web UI (React)** — отображает форму
- **Auth Service** — обрабатывает регистрацию
- **PostgreSQL** — хранит данные пользователей
- **Email Service** — отправляет письмо

### Временные связи

| Событие | Последующее событие | Условие | Задержка |
|---------|---------------------|---------|----------|
| E2 → E3 | Валидация успешна | Email корректен | 50 мс |
| E3 → E4 | Email уникален | Нет дубликатов | 100 мс |
| E4 → E5 | Пароль захеширован | BCrypt | 200 мс |
| E7 → E11 | Письмо доставлено | SMTP успех | 5-30 сек |
| E11 → E12 | Токен валиден | Не истёк | 100 мс |

### Точки синхронизации
- **После E3**: Обязательна проверка уникальности
- **После E7**: Асинхронное ожидание действия пользователя
- **После E11**: Проверка валидности токена

### Junction и альтернативные пути

**XOR Junction после UOB-2 (Валидация данных):**
- **Валидация успешна** → UOB-3 (Проверка уникальности)
- **Валидация не прошла** → UOB-5 (Обработка ошибки валидации)

**UOB-5: Обработка ошибки валидации**
- Input: Error details (некорректный email формат, слабый пароль)
- Process: Формирование сообщения об ошибке, логирование
- Output: HTTP 400 Bad Request с описанием ошибки
- **После UOB-5**: UOB-6 (Возврат ошибки пользователю)

**UOB-6: Возврат ошибки пользователю**
- Input: Error message
- Process: HTTP response с кодом ошибки
- Output: JSON response → Пациент
- **Конец процесса** (ошибка валидации)

**XOR Junction после UOB-3 (Проверка уникальности):**
- **Email уникален** → UOB-4 (Создание пользователя)
- **Email уже существует** → UOB-7 (Обработка ошибки дубликата)

**UOB-7: Обработка ошибки дубликата**
- Input: Email уже существует в БД
- Process: Формирование сообщения "Email уже зарегистрирован"
- Output: HTTP 409 Conflict с описанием ошибки
- **После UOB-7**: UOB-8 (Возврат ошибки пользователю)

**UOB-8: Возврат ошибки дубликата**
- Input: Error message
- Process: HTTP response с кодом 409
- Output: JSON response → Пациент
- **Конец процесса** (ошибка дубликата)

**XOR Junction после UOB-11 (Проверка токена):**
- **Токен валиден** → UOB-12 (Активация аккаунта)
- **Токен невалиден или истёк** → UOB-13 (Обработка ошибки токена)

**UOB-13: Обработка ошибки токена**
- Input: Токен невалиден или истёк
- Process: Формирование сообщения "Ссылка активации недействительна"
- Output: HTTP 400 Bad Request
- **После UOB-13**: UOB-14 (Возврат ошибки пользователю)

**UOB-14: Возврат ошибки токена**
- Input: Error message
- Process: HTTP response с описанием ошибки
- Output: HTML страница с ошибкой → Пациент
- **Конец процесса** (ошибка токена)

### UOB (Unit of Behavior)

**UOB-1: Валидация данных**
- Input: Email, Password
- Process: Regex validation
- Output: Валидированные данные или ошибка

**UOB-2: Проверка уникальности**
- Input: Email
- Process: SELECT FROM users WHERE email=?
- Output: Boolean (exists/not exists)

**UOB-3: Создание пользователя**
- Input: User data
- Process: Hash password, INSERT INTO users
- Output: User ID

**UOB-4: Отправка письма**
- Input: Email, Token
- Process: SMTP send
- Output: Message ID

### Временная диаграмма

**Успешный путь регистрации:**
```
t=0s      Начало регистрации (UOB-1: Заполнение формы)
t=0.05s   Валидация данных успешна (UOB-2) (50 мс)
t=0.15s   Проверка уникальности успешна (UOB-3) (100 мс)
t=0.35s   Хеширование пароля (UOB-4) (200 мс)
t=0.55s   Сохранение в БД (UOB-4 продолжение)
t=0.65s   Генерация токена активации (UOB-5)
t=0.75s   Отправка письма (UOB-6)
t=5-30s   Доставка письма (асинхронно)
...       Ожидание действия пользователя
t=X       Клик по ссылке активации
t=X+0.1s  Проверка токена успешна (UOB-11)
t=X+0.2s  Активация аккаунта (UOB-12)
t=X+0.3s  Конец процесса (успех)
```

**Путь ошибки валидации:**
```
t=0s      Начало регистрации (UOB-1)
t=0.05s   Валидация данных НЕ прошла (UOB-2) (50 мс)
t=0.06s   Обработка ошибки валидации (UOB-5) (10 мс)
t=0.07s   Возврат ошибки пользователю (UOB-6) (5 мс)
t=0.07s   Конец процесса (ошибка валидации)
```

**Путь ошибки дубликата email:**
```
t=0s      Начало регистрации (UOB-1)
t=0.05s   Валидация данных успешна (UOB-2)
t=0.15s   Проверка уникальности: email УЖЕ существует (UOB-3) (100 мс)
t=0.16s   Обработка ошибки дубликата (UOB-7) (10 мс)
t=0.17s   Возврат ошибки пользователю (UOB-8) (5 мс)
t=0.17s   Конец процесса (ошибка дубликата)
```

**Путь ошибки токена:**
```
t=X       Клик по ссылке активации
t=X+0.1s  Проверка токена: токен НЕВАЛИДЕН или истёк (UOB-11) (100 мс)
t=X+0.11s Обработка ошибки токена (UOB-13) (10 мс)
t=X+0.12s Возврат ошибки пользователю (UOB-14) (5 мс)
t=X+0.12s Конец процесса (ошибка токена)
```
